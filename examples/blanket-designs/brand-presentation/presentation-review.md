# 雾岸与日弧：品牌展示升级

更新日期：2026-11-14。交付偏好：电商品牌感，强调场景氛围、材质细节与有依据的设计特点。

## 本次改动

原案例的平铺效果图适合检查图案与边缘，但主视觉缺少使用情境；图、参数和说明的权重接近，阅读焦点不够集中。

本次保留两款毛毯的图案、颜色关系与收边意图，以原平铺图作为编辑参考生成沙发场景主图。展示板用同一主图的局部放大呈现织物与边缘，再以两条简短说明解释可见设计特点。文字与版式由可控排版完成，未让生图工具生成整页文案。

这次改善的是图像表达与展示层级，没有把毛毯重新设计，也没有重新完成一轮竞品视觉研究。原案例的两款竞品与艺术依据见[完整报告](../design-brief.md)；其中无法查看官方图片的证据限制仍然有效。

## 审美复查

| 项目 | 雾岸 | 日弧 |
| --- | --- | --- |
| 第一眼焦点 | 大面积米白毯体与两条绿色横带主导画面，沙发承托产品 | 蓝橙色块明显区别于中性场景，四个弧形可辨 |
| 使用与材料表达 | 披搭、折褶和定向柔光表达织物垂坠，细节保留可见针脚 | 较开放的披搭保留图案关系，局部能观察短边流苏 |
| 版面主次 | 主图最大，细节与两条说明次之，规格与概念标记置底 | 使用相同比例与信息层级，便于公平比较 |
| 多图关系 | 局部来自同一场景图，未另造纹理；原平铺图保留 | 局部来自同一场景图，未另造流苏；原平铺图保留 |
| 限制 | 单张生活场景仍不足以判断实际触感与质量 | 光线较原平铺图温暖，不能用截图代替色样与材质实测 |

展示板与两页 PDF 已逐页查看，检查了标题、正文、局部裁切、图幅和底部说明，没有发现文字遮挡或溢出。

## 场景图可见结构复核

| 方案 / 编号 | 观察证据 | 结果 |
| --- | --- | --- |
| 雾岸 P01 毯体 | 可见连续的薄软织物与自然折褶，没有新增拼接或填充表达 | 可见外观符合；真实材料、厚度与尺寸待打样 |
| 雾岸 P02 横带 | 两条全宽绿色横带、米白间隔与下摆均可辨，下条更深 | 可见图案关系符合；精确分区比例待制版 |
| 雾岸 P03 收边 | 可见左、右及下边细绿针脚，无流苏与厚包边 | 可见部分符合；上边与折叠处遮挡，未判为已核实 |
| 日弧 P01 毯体 | 单片棉织物意向，无明显拼缝、填充或衬底 | 可见外观符合；实际纤维与背面组织待打样 |
| 日弧 P02 图形 | 四个杏橙弧形保持 2×2，上排弧面内向、下排外向 | 数量与朝向符合；曲线受透视与折褶影响，不能当作制版线 |
| 日弧 P03 短边 | 上下两短边可见本白流苏 | 边缘分配符合；长度及根部防脱散待验证 |
| 日弧 P04 长边 | 左右长边为蓝色窄收边，没有新增流苏 | 可见部分符合；与沙发接触区域及背面未观察 |
